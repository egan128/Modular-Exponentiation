# Modular-Exponentiation
A project written in C that calculates powers in modular number systems (for example 2^644 in mod645) using a recursive algorithm and without the use of the C math library. 
I decided to do this project when studying the topic of Modular Exponentiation in my maths module, where we were taught to calculate large powers of numbers inside a modular number system. This project when complete will be a good aid when studying to instantly find out if my answer to a problem is correct.
